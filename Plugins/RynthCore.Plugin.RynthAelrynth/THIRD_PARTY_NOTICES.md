# Third-party notices: RynthAelrynth

RynthAelrynth's quest pack (`Resources/quests.aelrynth.csv`, offered to RynthOracle's Quests tab
through "RynthServer.QuestPack") is generated from Aelrynth's own world database by
`Tools/RynthOracle.QuestPackGen`. Where a quest is also in **Oracle of Dereth**'s master quest list
(the Decal plugin for Asheron's Call by **Advis Eveldan**, GitHub:
[advis61](https://github.com/advis61/OracleOfDereth)), RynthOracle keeps that list's name and notes
and the pack only adds Aelrynth's timers and who sets the flag; a flag only another server's pack
knows takes that pack's text, which is Advis's. The pack was part of RynthOracle until 2026-10-21
and moved here, with the server it belongs to. Thank you, Advis!
